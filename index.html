How the way I write software has changed in three years.

  1. 2023

    Chat

    Copying code into chatgpt.com and pasting the answers back.

  2. 2023–24

    Autocomplete

    GitHub Copilot in the editor: faster typing, same way of working.

  3. 2024

    AI in the product

    Built a fine-tuned OpenAI model into Overvinne's daily mood report, with a sandbox for safe testing.

  4. 2025

    Agents in the IDE

    JetBrains AI and Junie, then Claude Code: describing the change instead of typing it.

  5. 2026

    A harness

    Praive: agents work under a written contract, with review gates and tests that must pass before anything merges. I set the direction and review; agents open the pull requests.

  6. Now

    Fully agentic

    Nightly jobs and parallel agents ship across seven projects: 6,600+ commits and 2,500+ merged pull requests so far, with me as operator rather than typist.
